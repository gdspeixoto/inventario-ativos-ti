# Glossario

- Ativo: qualquer item controlado pelo sistema, como licenca, servidor, contrato ou servico.
- Tenant: isolamento logico de dados e configuracoes.
- Unidade organizacional: no da arvore institucional.
- Negocio: divisao organizacional acima de areas tecnologicas.
- Area tecnologica: agrupamento tecnico ou estrategico dentro de um negocio.
- Unidade operacional: unidade de operacao vinculada a uma area tecnologica.
- Nucleo de suporte: nucleo operacional ou de apoio.
- Reajuste: alteracao financeira controlada com valor anterior, novo valor e motivo.
- Timeline: historico auditavel de eventos de uma entidade.
- BFF: Backend For Frontend, camada backend que protege tokens do navegador.
- RLS: Row-Level Security do PostgreSQL para isolamento no banco.
